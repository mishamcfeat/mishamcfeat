## What I do

I build payment infrastructure, mobile SDKs and full-stack products. My work spans Swift and Kotlin client architecture, event-driven backend services, checkout reliability, observability and CI/CD.

Most of my production work is private. Here is the impact I can share:

```text

[backend]      Reduced API latency by 40% through Java, PostgreSQL and Redis tuning

```
